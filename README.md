Project for FSH Code Challenge

Link: https://endlessrequiem.github.io/fsh-fe-engineer-assignment/

Features:
- Dashboard for viewing upcoming/past appointments
- Appointment creation, edit, and delete
- Search bar to help find specific appointments
- Test suite that covers core functionality
- Responsive design

Uses
- React
- TypeScript
- Vite
- Redux
- Jest (tests)

If you want to run it locally, you just to run the below command 
```bash
# Start development server
yarn dev
```
 Site will be available here: http://localhost:5173/fsh-fe-engineer-assignment/
